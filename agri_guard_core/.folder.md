# Folder: /agri_guard_core

**地位**: AI 核心引擎，独立的 Python 包，封装 YOLOv8 检测算法和图像处理逻辑，不依赖业务层。

**逻辑**: 
- 接收图像数据 → 预处理（切片、格式转换）→ YOLOv8 推理 → 后处理（坐标投影、结果聚合）→ 返回检测结果
- 输入/输出接口应明确，便于替换不同的 AI 模型
- 支持批量处理和单图像处理

**约束**: 
- ✅ **必须**保持独立，不依赖 `agri_guard_api` 的业务逻辑
- ✅ **应该**提供清晰的输入/输出接口（类型提示）
- ✅ **可以**使用 NumPy、PIL、OpenCV 等图像处理库
- ❌ **禁止**直接访问数据库或外部服务
- ❌ **禁止**包含业务规则（如任务状态、权限检查）
- ✅ 检测结果应包含：边界框坐标、置信度、类别 ID、GPS 坐标（如适用）
- ✅ `pil_open` 在首次 import 时绑定原生 `PIL.Image.open`，供 metadata/slicing 使用，避免 Ultralytics 对 `Image.open` 的补丁把普通 DJI JPEG 拐到 HEIF 依赖链；仍会正确 `close`/`with` 防止 FD 泄漏。

**成员清单**:
- `src/agri_guard_core/`: 核心检测算法实现
  - 检测器类（Detector）
  - 图像预处理工具
  - 坐标投影工具
  - 结果聚合工具
